This post presents a data visualization for my senior project, **"Structural Controls on Fluvial Channel Architecture and Reservoir Distribution in Suphanburi Basin, Thailand."**

## Well Log Analysis for Reservoir Distribution

The plot below was generated using Python (`pandas` and `matplotlib`) to visualize well log data. By analyzing the Gamma Ray (GR) and Porosity logs, we can identify potential sandstone reservoirs within the fluvial channel system.

![Fluvial Channel Reservoir Plot](/images/Fluvial_Reservoir_Plot.png)

### Description
The graph illustrates the reservoir distribution within a fluvial channel system. The yellow shaded area represents zones where the Gamma Ray value is below the 75 API cut-off, indicating high-porosity sandstone layers (good reservoir quality). This "bell shape" or fining-upward sequence is a typical geological signature of fluvial channel deposition.
